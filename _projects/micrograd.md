Engineered a custom Value class supporting reverse-mode autodiff, core math operations, and dynamic computation graph generation via topological sort.

Architected Neuron, Layer, and MLP classes closely replicating the standard PyTorch API structure.

Validated the engine by training an MLP on a classification dataset with custom gradient descent, visualizing backprop graphs with Graphviz.
